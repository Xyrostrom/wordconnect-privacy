# Word Connect — privacy policy

The published privacy policy for the Android app `com.shikhar.crossword`.

This repository is public only so GitHub Pages can serve the page; the game's
source lives in a separate private repository. The page itself is kept in the
game's repo under `docs/privacy.html` — edit it there and copy it here, so the
published policy and the app it describes never drift apart.

Published at: https://xyrostrom.github.io/wordconnect-privacy/
